## ✦ The Atelier — Project Structure

<br>

```
E-Fashion/
│
├── app/             → routes & pages (App Router)
├── components/      → reusable UI pieces (shadcn/ui based)
├── hooks/           → custom React hooks
├── lib/             → shared utilities
├── public/          → static assets
└── styles/          → global styling
```

## ✦ Getting Ready — Setup

<br>

**Requirements:** Node.js 18+ · pnpm (or npm)

```bash
git clone https://github.com/demianeid/E-Fashion.git
cd E-Fashion
pnpm install
pnpm dev
```

Open **`localhost:3000`** and start browsing.
